# discovery

## Trigger

Interrogate an unclear idea before deciding scope. Load only for the relevant lifecycle stage in AGENTS.md.

## Scope

Ask what user, problem, outcome and constraint matter. Challenge every major assumption without being adversarial.

## Procedure

1. Restate the problem and the target user in one paragraph.
2. Ask up to five high-leverage questions at a time; prioritize blockers, not preferences.
3. Stress-test with non-happy paths: permissions, failures, data lifecycle, cost, privacy and accessibility.
4. Separate confirmed facts, hypotheses and open decisions.
5. Produce a short discovery brief with user journeys, success metric, MVP and explicit exclusions.

## Deliverable

A discovery brief with decisions, unresolved questions, measurable outcome and MVP boundary.

## Exit check

Do not invent answers. If user is unavailable, record assumptions and request approval before irreversible implementation.

## Conflict policy

AGENTS.md owns phase order and human approval gates. This skill does not supersede another lifecycle stage, tool permissions, or repository rules.
