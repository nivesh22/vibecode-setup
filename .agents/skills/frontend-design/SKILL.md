# frontend-design

## Trigger

Build usable interfaces within the approved architecture. Load only for the relevant lifecycle stage in AGENTS.md.

## Scope

Use design systems and UX evidence; do not add a new planning controller.

## Procedure

1. Identify design tokens, information hierarchy and component states before styling.
2. Use semantic HTML, keyboard navigation, focus treatment, labels and contrast-aware colors.
3. Plan loading, error, empty and mobile states explicitly.
4. Reuse established components; avoid needless dependencies and visual inconsistency.
5. Validate on mobile and desktop viewports and capture accessibility evidence.

## Deliverable

Reusable components, responsive screenshots/notes and component tests.

## Exit check

Core journeys work via keyboard, are responsive and have tested error/empty states.

## Conflict policy

AGENTS.md owns phase order and human approval gates. This skill does not supersede another lifecycle stage, tool permissions, or repository rules.
